# Trayvi Brand Kit v2.2 — Clean Vector

This version preserves the approved Trayvi concept while replacing the rough auto-traced symbol geometry in v2.1 with deliberate vector curves and negative-space construction.

## Source hierarchy

1. `svg/` contains the editable masters.
2. `png/` contains generated delivery exports.
3. `reference/` contains comparison and approval material.

The v2.1 package remains unchanged for comparison and rollback. v2.2 is a candidate until the owner visually approves the cleaned geometry at large and small sizes.

## What changed

- Rebuilt the T/V/pin/route symbol with smooth paths.
- Removed traced spikes, isolated pixels, and irregular joins.
- Made the route and pin center true negative space so the mark works on light and dark backgrounds.
- Preserved the approved geometric TRAYVI wordmark.
- Added full-bleed square app-icon artwork with a conservative safe area; operating systems apply their own masks.
- Added accessible SVG titles/descriptions and removed all external dependencies.
- Aligned token names with the project design documentation.

See [Brand Guidelines](docs/BRAND_GUIDELINES.md) for usage and remaining production decisions.
